Offline AI Setup Guide

Recommended default: local sidecar using an Ollama-compatible HTTP service on 127.0.0.1.

  1. Install the local model runtime on the trusted host machine.
  2. Pull a supported model such as qwen2.5:7b-instruct or llama3.1:8b.
  3. Set ai_mode=local_sidecar and ai_base_url in the NITMEXS config.
  4. Use the Admin Review tab to verify AI health and suggestions.
