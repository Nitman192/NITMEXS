NITMEXS

Admin User Manual

Networked Integrated Training, Monitoring, Evaluation and eXamination Suite

  1. Login only from the trusted host machine.
  2. Create or load an exam, then attach questions and publish the exam.
  3. Use Live Control for pause, resume, broadcast, and force-submit actions.
  4. Review FIB and subjective queues before publishing final results.
  5. Use Results and Downloads to preview, print, and export reviewed results.
